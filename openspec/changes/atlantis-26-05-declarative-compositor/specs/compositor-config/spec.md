## Purpose

The Hyprland session configuration contract: the compositor's configuration
is generated by home-manager from Nix attrs as the single source of truth,
per-host display topology comes from host-level attrs, and no hand-edited
config files participate in the session.

## ADDED Requirements

### Requirement: Home-manager generates the compositor config

The Hyprland session configuration SHALL be generated by home-manager's
`wayland.windowManager.hyprland` module in Lua form, covering binds,
environment, autostart, look-and-feel, input, and window rules. The
repository MUST NOT carry a root `hyprland.conf` that Hyprland could prefer
over the generated file.

#### Scenario: Generated config is authoritative
- **WHEN** the user profile is activated on a host
- **THEN** `~/.config/hypr/hyprland.lua` is a symlink into the Nix store and
  no `~/.config/hypr/hyprland.conf` exists to shadow it

### Requirement: Per-host display topology comes from host attrs

Monitor layout and workspace-to-monitor banks SHALL be declared as
`wayland.windowManager.hyprland.settings.monitor` and `.workspace_rule`
attrs in each host's `home.nix`, not sourced from external files.

#### Scenario: blackhand triple-head layout
- **WHEN** the blackhand user profile evaluates
- **THEN** the monitor list contains DP-3 (portrait, transform 1),
  DP-2 (3840x2160@60, scale 1.5), and DP-1 (portrait, transform 3), with
  workspace banks 1-9 on DP-3, 11-19 on DP-2, and 21-29 on DP-1

#### Scenario: spider single-head layout
- **WHEN** the spider user profile evaluates
- **THEN** a single auto/preferred monitor entry is present and no explicit
  workspace-to-monitor mapping is required

### Requirement: Session support packages come from the home layer

Programs the session autostarts or binds to (waybar, hyprpaper, wofi, grim,
slurp, wl-clipboard) SHALL be installed via `home.packages` in the Hyprland
home-manager module, not `environment.systemPackages` in a NixOS module.

#### Scenario: WM helper packages resolve in the session
- **WHEN** a Hyprland session starts on either host
- **THEN** waybar, hyprpaper, and wofi are on PATH and the screenshot bind
  (`grim -g "$(slurp)" - | wl-copy`) executes successfully

### Requirement: Portal wiring satisfies home-manager 26.05

Both host configurations SHALL link `/share/applications` and
`/share/xdg-desktop-portal` via `environment.pathsToLink` so the
xdg-desktop-portal integration enabled by the compositor module satisfies
the home-manager `useUserPackages` assertion.

#### Scenario: Portal assertion passes at eval time
- **WHEN** either host's configuration is evaluated with the compositor
  module enabled and `useUserPackages = true`
- **THEN** evaluation succeeds without the pathsToLink assertion firing
